# Plan — shared heavy-job slot pool (architect, Opus)

Contracts
- Lock dir (both sides): AL_RUNNER_LOCK_DIR else /tmp/al-runner-slots-<euid> (literal /tmp). Create 0700; reject symlink / cannot create / not a directory / not owned by uid / group-other writable (mode&0o022). Slot file i (1-based): <dir>/slot-<i>, never deleted/truncated. Bridge: non-regular slot path => busy, warn once per slot.
- Total: bridge maxParallelAlc() unchanged (int>=1 else 2). Wrapper reads AL_BRIDGE_MAX_PARALLEL_ALC via num() default 2; invalid => "ignoring AL_BRIDGE_MAX_PARALLEL_ALC='x' (not a positive integer); using 2". No new neutral name.
- Bridge helper (Linux): `flock -o -n -E 75 <dir>/slot-<i> sh -c 'echo held; exec cat >/dev/null'`, stdio pipes, not detached. First stdout line `held` = held; exit 75 = busy; ENOENT / exit 64 = flock unusable (cache, fall back); other exit or no answer in 5 s = kill, busy, warn once. Lock dies with the bridge (stdin EOF). release(): stdin.destroy(); kill SIGKILL; idempotent. Never end stdin early; handle error events.
- src/tools/sharedSlots.ts (new): SLOT_BUSY_EXIT, sharedSlotDir(env, euid), checkSharedDir(dir): string|null, tryHoldSlot(file, flockPath), acquireSharedSlot(...).
- alcSlots.ts: Slot = {release(); backend: "flock"|"legacy"; warning?}. SlotOptions add platform, sharedDir, flockPath, noticeEveryMs (default WAIT_NOTICE_MS=15000, exported). linux => shared pool; unusable dir / flock => legacy pool + warning "shared heavy-job cap NOT enforced (<reason>); alc runs are capped among bridges only, test runs are not counted (AL_BRIDGE_MAX_PARALLEL_ALC=<N>)". Non-linux => legacy unchanged (acquireLegacySlot). Abort with slot taken => release, CancelledError. BUSY text keeps "BUSY:" prefix; wait notice keeps phrase "alc slot". pidAlive export stays.
- compile.ts: AlcCompileRun.slotWarning; al_compile joins into `warning`; exported pure withSlotWarning(result, w). compileDelta/index.ts: push slotWarning into environment.hints (deduped).
- Wrapper: after runner-exists check, before bypass: if AL_RUNNER_SLOTS set (-v), print once "al-runner: ignoring AL_RUNNER_SLOTS (no longer used) - the total of concurrent compiles and test runs is set by AL_BRIDGE_MAX_PARALLEL_ALC (default 2)". slots from AL_BRIDGE_MAX_PARALLEL_ALC default 2. Everything else unchanged (exit 75, notices, bypass, unthrottled).

Tests: bridge tests/unit/sharedSlots.test.mjs (linux-only skips, tmp sharedDir, pollMs 20; xwrap tests gated by AL_RUNNER_WRAPPER); compileDeltaCache legacy tests get platform:"win32". Wrapper test_al_runner.py: make_env default AL_BRIDGE_MAX_PARALLEL_ALC=1, bridge-holder helper = the helper command line; new tests per AC (see AC->test map in conversation of the architect: AC1..AC13 each have bridge and/or wrapper test).
Docs: bridge README lines ~173 (AL_BRIDGE_MAX_PARALLEL_ALC row, AL_RUNNER_LOCK_DIR row, AL_RUNNER_WRAPPER); claude-trto trto-al/README.md ~98-111; plugin.json 6.12.0 -> 6.13.0; run scripts/twins/check-twins.sh; no bridge version bump.
Risks: orphaned alc after SIGKILL; release async (poll in tests); env split of AL_RUNNER_LOCK_DIR undetected (documented).
